3. Open index.html in your browser to start playing!


## 🔧 How it Works
- Players: Take turns placing X or O on the grid.
- Objective: The first player to align three marks (horizontally, vertically, or diagonally) wins.
- Draw: If all cells are filled without a winner, the game results in a draw.
